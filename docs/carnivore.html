hakoniwa 肉食獣図鑑 ▲

肉食獣（CarnivoreState）に限定した見た目とパラメータのまとめ。全体のモデル（因果ループ・1 tickの処理順・不変条件）は docs/manual.html を参照。数値の正は src/sim/params.ts、見た目のベクタ図形は src/render/sprites.ts の drawTigerShape / TIGER_POSES をそのままJSに写して動かしている（このページ独自の演出は無い）。

1. アイコン（見た目の言語）

細身の箱型ボディ＋縞模様（design.md：鋭い輪郭＝肉食）
  • 草食獣より縦に薄く（bh = r×0.6）、角も立っている（cr = r×0.22）
  • 縞は暖色寄りの濃茶（黒ではない）、口は赤系（TIGER_MOUTH_COLOR）
  • 目・歯は無し。口の開閉と体の動きだけで「食べている」を表現する
  • 常に右向きで焼き込み、左向き個体は描画時に左右反転（このページでは常に右向き）

空腹度による色の変化

体色は5段階の空腹バケット（ANIMAL_HUNGER_BUCKETS）で 橙（満腹）→ くすんだ赤茶（餓死間近） に線形補間される。hunger は0=満腹、1=starvationHunger（餓死）。

2. 状態ごとの動くアイコン

実装上、個体は毎tick 休憩中フラグ（rest > 0）で「移動・空腹・捕食を丸ごとスキップする」か「移動して狩る」かの2択（stepCarnivores、sim/carnivore.ts）。アニメーションは8フレームを「歩き」（0〜4）と「捕食」（5〜7）の2ループに分け、捕食が成立したそのtickだけ捕食ループを再生する（pickAnimalFrame、manual.html 5章）。以下のカードはそれぞれ独立にループ再生しているが、実際のゲームでは①→②→③の順に1回ずつしか起きない（③のあとは①に戻る）。

① 索敵中（歩き）通常

rest === 0：隣8タイル＋自タイルのうち、未捕獲の草食獣が一番多いタイルへ1マス移動

口はほぼ閉じたまま、わずかな上下動と耳の動きだけ（フレーム0〜4）。毎tick hunger += hungerGainPerTick（0.04）で空腹度が上がる。

② 捕食成功（噛みつき）1 tickだけ

移動先タイルに草食獣がいれば1体捕獲。hunger −= predationRelief（0.3）、rest = restTicksAfterEating（1）をセット

口を大きく開閉する一噛み（フレーム5〜7）。実際は捕食が成立したtick自体（獲物のいたタイルへ歩いている最中）に1回だけ再生される——このカードは分かりやすさのためループ表示にしている。捕らえた草食獣はその場に死骸を残さず消え、同じ座標に汎用シルエットが縮小・フェードアウトする「被食シーン」が重なる（manual.html 5章）。

③ 休憩中（消化）凍結

rest > 0：移動・空腹の上昇・次の捕食判定をまるごとスキップ

位置も空腹度も1tickの間そのまま凍結する。restTicksAfterEating（1）が1なので、②の直後にちょうど1 tickだけこの状態を経て①へ戻る。口は閉じた歩きポーズのまま静止（このtickでは捕食ループの再生条件を満たさない）。

④ 死亡 → 死骸餓死／老衰

hunger ≥ 1（餓死）または age > lifespanTicks（600、老衰）

その場に死骸を1つ残して個体は消える（脚を硬直させ広げ、縞模様は残したまま）。色は新鮮な赤（CARCASS_FRESH_COLOR）から土色（CARCASS_DECAYED_COLOR）へ、decayTicks（10 tick）かけて褪せる。分解し終えると消滅し、CARCASS_PARAMS.fertility（0.4）が土壌養分として返る。

⑤ 繁殖（新生）無性生殖

生き残り、かつ hunger ≤ reproHungerThreshold（0.05）で自分のいるタイルに子を1体

子は initialHunger（0.5、中間の空腹バケット）でその場に現れる——専用の見た目や誕生アニメーションは無く、次のtickから①と同じ歩きループに合流する。親は hunger += reproHungerCost（0.7）。草食獣（しきい値0.15／コスト0.3）よりずっと厳しく、何度も捕食を重ねないと繁殖できない（少産少死、manual.html 4.1章）。

3. パラメータ

src/sim/params.ts の CARNIVORE_PARAMS（および死骸周りの CARCASS_PARAMS、両種共通）の写し。数値の正はソース。

パラメータ値意味
capacity150個体数の上限（草食獣の2000に対し、捕食者は十分少なく保つ）
initialCount12起動時の初期個体数
hungerGainPerTick0.041tickごとに空腹度が上がる量（草食獣0.05より遅い＝少し長く持つ）
predationRelief0.31回の捕食で空腹度が下がる量
starvationHunger1.0これに達すると餓死
initialHunger0.5誕生時（初期配置・繁殖）の空腹度
reproHungerThreshold0.05これ以下でないと繁殖できない（草食獣0.15より厳しい）
reproHungerCost0.7繁殖のたびに親の空腹度が上がる量（草食獣0.3より重い）
restTicksAfterEating1捕食成功tickの直後、動かず消化に費やすtick数
lifespanTicks600（約1200秒）これを超えると老衰死（草食獣200の3倍）
パラメータ（共通・CARCASS_PARAMS）値意味
fertility0.4死骸1体が分解し終えるまでに返す土壌養分の総量（種によらず一定）
decayTicks10（約20秒）発生してから消えるまでの実質tick数
ピラミッドの原則：肉食獣は食物連鎖の上の段ほど「少なく・遅く・長生き」（design.mdの少産少死）。上限個体数・初期個体数・繁殖しやすさは草食獣より小さく／厳しく、寿命は3倍長い。詳しい比較表は manual.html 4.1章。
