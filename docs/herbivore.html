草食獣 図鑑

ピラミッド最下段、草を食べる側の種族についてのアイコン・状態別アニメーション・パラメータのまとめ。

数値の正は src/sim/params.ts、処理順・不変条件はマニュアル本体（4.3 草食獣、7章）を参照。この文書はそこから草食獣だけを抜き出して見た目つきで整理したもの。

アイコン

丸みを帯びた箱型の体に、四角い口（src/render/sprites.ts の drawHerbivoreShape）。角や牙は無く、捕食される側として柔らかく見える。体色は健康な橙褐色から、空腹が進むほど鈍い灰褐色へ連続的に沈む。

空腹度 hunger による色の変化

0.0 満腹 0.15 繁殖可 1.0 餓死

状態別アニメーション

見た目に現れる状態は3つ。「休憩」は独立した見た目を持たず、噛みアニメの再生が終わった後は徘徊と同じ穏やかな姿勢で静止するだけ。

徘徊

草が一番多い隣接タイルへ1マス移動。口はほとんど閉じ、軽い上下動と耳の揺れだけ。rest === 0 の間のデフォルト姿勢。

採食

草0.1超のタイルで最大0.15食べ、口を大きく開閉する。この後 restTicksAfterEating（2 tick／4秒）休む。噛みアニメが映るのは休憩の最初の1tickだけ（INV-17）。

死骸

餓死・老衰で発生。生々しい赤から土色へ色が抜け、分解が終わると消える（実質10 tick／約20秒。表示はデモ用に速めてある）。分解中はこのタイルに他個体が移動できない。

パラメータ

実時間は既定の DEFAULT_TICK_MS = 2000ms（1 tick = 2秒）換算。速度調整UIで変わる。

src/sim/params.ts — HERBIVORE_PARAMS
パラメータ値実時間意味
capacity2000—個体数の上限（配列の物理サイズ）
initialCount150—起動時の初期個体数
hungerGainPerTick0.05—空腹度の毎tick上昇量。無補給なら20 tickで餓死ラインに達する
grazeHungerRelief0.1—一口（最大0.15食べた分）で下がる空腹度
grazeBiomassThreshold0.1—これを超える草があるタイルでしか食べられない
starvationHunger1.0—これ以上になると餓死
initialHunger0.5—誕生時（子・初期個体とも）の空腹度
reproHungerThreshold0.15—これ以下でなければ繁殖できない（過去の蓄えは無効）
reproHungerCost0.3—繁殖時に親の空腹度に加わる量
restTicksAfterEating2 tick4秒採食後、移動・再摂食を止めて静止する長さ。空腹度も凍結
excretionRatio0.5—食べた量のうち、そのタイルの養分へ還す割合（排泄）
lifespanTicks200 tick約400秒この年齢を超えると老衰死
visionRadius3—定義済みだが未接続。移動判定は常に隣接8タイルのみで、この値は現在どこからも参照されていない

パラメータ値実時間意味
